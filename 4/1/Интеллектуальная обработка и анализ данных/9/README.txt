Лабораторная работа № 9 — Контурный анализ

Состав проекта
--------------
- Lab_9_Contour_analysis_completed.ipynb — ноутбук с кодом, выполненными ячейками, графиками и ответами на 8 контрольных вопросов.
- Lab9_images/camera.jpg — реальная фотография для анализа границ.
- Lab9_images/coins.jpg — реальная фотография монет для контуров и HoughCircles.
- Lab9_images/brick.jpg — реальная фотография кирпичной кладки для подсчёта прямоугольных контуров.
- Lab9_output/ — примеры вырезанных объектов (повторно создаются при запуске ячейки 2).

Установка
---------
pip install opencv-python numpy matplotlib pandas jupyter

Запуск
------
1. Распакуйте архив целиком, не перемещая папку Lab9_images отдельно от ноутбука.
2. Откройте Lab_9_Contour_analysis_completed.ipynb в Jupyter Notebook/Lab.
3. Запустите ячейки по порядку сверху вниз.

Собственные фотографии
----------------------
Методичка требует фотографии реального мира. Для наиболее точного соответствия заданию сфотографируйте реальные объекты и добавьте фото в папку Lab9_images:
- my_edges.jpg — для Sobel, Laplacian и Canny;
- my_objects.jpg — несколько предметов на однотонном контрастном фоне;
- my_circles.jpg — несколько круглых предметов, лучше сверху;
- my_shapes.jpg — реальные геометрические предметы на простом фоне.

Если файл my_*.jpg найден, код использует его вместо фотографии из комплекта. Если пользовательского фото нет, код использует фотографию из комплекта, чтобы ноутбук выполнялся офлайн. Демонстрационные фотографии — реальные фотографии из набора `scikit-image` (skimage.data.camera, skimage.data.coins, skimage.data.brick), а не изображения, нарисованные программно. Для фотографий из комплекта см. документацию: https://scikit-image.org/docs/stable/api/skimage.data.html.

Задание 2 на снимке монет демонстрирует выделение нескольких отдельных объектов; для собственной фотографии с предметами разной формы может понадобиться изменить минимальную площадь контура и способ бинаризации. Задание 4 на образце кирпичной кладки считает прямоугольные контуры; для фотографирования треугольников или смеси фигур добавьте собственное my_shapes.jpg.
